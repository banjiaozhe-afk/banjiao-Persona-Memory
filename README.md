# Persona Memory

为 AI 虚拟主播管理稳定人格、对话摘要和按需检索的长期记忆，避免把所有历史内容堆入模型上下文。

## 当前状态

当前是 `v0.0.1` 项目骨架，尚无人格管理、记忆写入、记忆检索或模型调用功能。第一个计划实现的小功能是：输入当前消息，输出包含精简人格、当前状态和少量相关记忆的上下文。

## 怎么装

- 操作系统：Windows。
- 语言、模型接入方式、记忆数据库及依赖：选型待定，需用户确认后实施。
- 当前骨架不需要安装依赖，也不需要 GPU 或联网。
- 后续如使用需要密钥的模型服务，复制 `.env.example` 为 `.env` 后填写；真实密钥不得提交。

## 怎么跑

业务功能尚未实现。当前只能验证仓库基线是否完整：

```bash
git status --short --branch
git log --oneline --decorate -1
```

## 怎么验证跑对了

- 第一条命令应显示当前位于 `main` 分支；刚验收基线时不应列出未提交文件。
- 第二条命令应显示 `chore: 初始化项目骨架`，并带有 `tag: v0.0.1`。
- 待首个业务功能完成后，这里必须补充可复制的运行命令、预期输出和自动化验证方式。

## 目录结构

| 路径 | 放什么 |
|---|---|
| `src/` | 后续的人格、记忆与上下文组装源码 |
| `config/` | 后续的人格配置和非密钥运行配置 |
| `assets/` | 后续需要随项目分发的少量静态资源 |
| `docs/` | 技术决策及其原因 |
| `output/` | 后续运行产物，已被 Git 忽略 |

## 已知限制

- 当前没有可执行的业务程序。
- 尚未确定 LLM、嵌入模型、向量检索和持久化方案。
- 尚未实现记忆去重、冲突处理、遗忘、敏感信息过滤及提示词边界。
